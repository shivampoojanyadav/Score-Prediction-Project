# Score Prediction Project

## Overview

This is a beginner Machine Learning project that predicts a student's exam score based on the number of hours studied using Linear Regression.

The project demonstrates the basic workflow of a machine learning model, including data loading, model training, evaluation, visualization, and prediction.

## Dataset

The dataset contains:

* Hours Studied
* Exam Score

File used:

* `student_exam_scores.csv`

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Project Workflow

1. Load and explore the dataset
2. Prepare input and output variables
3. Train a Linear Regression model
4. Evaluate model performance using:

   * MAE (Mean Absolute Error)
   * MSE (Mean Squared Error)
   * RMSE (Root Mean Squared Error)
   * R² Score
5. Visualize data using:

   * Histogram
   * Scatter Plot with Regression Line
6. Predict exam scores for new study hours

## Results

The model learns the relationship between study hours and exam scores and predicts the expected score for a given number of study hours.

## Learning Outcomes

Through this project, I learned:

* Data preprocessing with Pandas
* Linear Regression using Scikit-learn
* Model evaluation metrics
* Data visualization with Matplotlib
* Making predictions using trained ML models
